# WEBCRAFT

كتالوج تفاعلي لتصميم موقع مع معاينة مباشرة، تسجيل دخول، إرسال طلبات، ولوحة إدارة. الواجهة عربية RTL، ويمكن معاينة تصميم LTR ومقاسات الكمبيوتر واللوحي والجوال.

تستخدم واجهة WEBCRAFT خط `thmanyah sans` بصيغة OpenType ‏(OTF) في المعاينة المحلية. يقرأ خادم التطوير الملفات من `Thmanyah-Font-Family.zip` في مجلد Downloads؛ ويمكن تحديد موقع الأرشيف بمتغير `THMANYAH_FONT_ARCHIVE`. أمر `npm run dev` يربط الخادم بـ `127.0.0.1` فقط. لا تُضمّن الملفات في حزمة المصدر أو الإنتاج؛ وفي الإنتاج يُستخدم Cairo بدلًا منها. ترخيص الأرشيف يمنع إتاحة ملفات الخط للزوار عبر الويب، ولذلك يلزم إذن مناسب من صاحب الخط قبل نشرها لموقع عام.

## التشغيل

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`، أو `/builder` للمشاريع، أو `/login` للدخول، أو `/signup` لإنشاء حساب، أو `/admin` للإدارة. الدخول وإنشاء الحساب يستخدمان البريد وكلمة المرور مباشرة، دون OTP.

## إعداد Supabase

1. أنشئ مشروع Supabase. من **Project Settings → API Keys** انسخ Project URL وPublishable key وSecret key. يمكن استعمال مفتاح `service_role` القديم بدلاً من Secret key. ضعها في `.env.local` وفق `.env.example`. المفتاح السري للخادم فقط ولا يوضع في متغير يبدأ بـ `NEXT_PUBLIC_`.
2. نفّذ [`supabase/schema.sql`](./supabase/schema.sql) في SQL Editor لإنشاء الجداول والدوال والصلاحيات. هذا ضروري قبل تشغيل الحفظ أو لوحة الإدارة.
3. في **Authentication → Sign In / Providers → Email** فعّل البريد وكلمة المرور، وأوقف **Confirm email** لإنشاء الحساب دون OTP أو رسالة تأكيد. إذا بقي هذا الخيار مفعّلًا، سيرسل Supabase رسالة تأكيد تلقائيًا وسيوقف الموقع التسجيل المباشر برسالة توضّح الإعداد المطلوب. اضبط Site URL على عنوان الموقع.
4. أعد تشغيل `npm run dev`. افتح `/api/status`؛ `{"supabase":true}` تعني نجاح قراءة قاعدة البيانات.
5. سجّل دخول الإدارة بالبريد وكلمة المرور من `/login`، ثم نفّذ في SQL Editor بعد استبدال البريد:

```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'admin@example.com'
on conflict (user_id) do nothing;
```

ثم افتح `/admin` بالحساب نفسه. دخول المستخدم العادي لا يمنح صلاحيات الإدارة.

لكل عميل قائمة مشاريعه. صاحب المشروع يستطيع إضافة حتى 20 محررًا لديهم حسابات في المنصة من زر «المتعاونون» داخل المحرر. المحررون يحررون التصميم، وصاحب المشروع وحده يضيف أو يزيل المتعاونين ويرسل طلب التصميم. يظهر تعارض النسخ برسالة تطلب إعادة تحميل المشروع حتى لا تُستبدل تعديلات شخص آخر بصمت.

## البيانات والأمان

- `projects`: تصميم المشروع وصاحبه وبريد صاحبه ورقم نسخته؛ `project_members`: المحررون.
- `designs`: نسخة التصميم وقت إرسال الطلب؛ `requests`: بيانات التواصل والحالة وهوية العميل والمشروع؛ إدخالهما يتم في عملية SQL واحدة.
- `shares`: رابط معاينة تصميم ينتهي بعد 30 يومًا ولا يتضمن بيانات التواصل.
- `catalog_components` و`color_palettes`: تعديلات القوالب ولوحات الألوان من `/admin/catalog`.
- `request_throttle`: عداد حدود الطلبات والمشاركة؛ `admin_users`: حسابات الإدارة؛ `settings`: فحص الاتصال.

تستخدم صفحة الحساب Supabase Auth للدخول بكلمة المرور. بعد التحقق من الجلسة، ينشئ الخادم إثباتًا موقّعًا بملف تعريف ارتباط محمي، ويتحقق منه في كل طلب للمشاريع والإدارة. يستخدم خادم Next.js المفتاح السري بعد التحقق من هوية المستخدم وصلاحية كل مشروع أو من هوية المدير في كل طلب إداري. الجداول مقيّدة بـ RLS ولا توجد سياسات تتيح للمتصفح قراءة بيانات العملاء مباشرة. التحقق من الحقول وحدود الأحجام يتم على الخادم، وحدود الإنشاء والمشاركة مرتبطة بهوية المستخدم. احفظ `.env.local` خارج المستودع، ودوّر أي مفتاح سري تم نشره.

## القوالب والأسعار

تعرض الصفحة الرئيسية ستة قوالب جاهزة للبدء، مع أسعار بداية ظاهرة، وجدول أسعار لعشرة أنواع من المواقع وحاسبة للإضافات. الأسعار التقديرية بالريال العُماني (OMR): الصفحة الإضافية 30، المدونة 80، نظام الحجز 120، كتالوج المنتجات 240، اللغة الثانية 150، وكتابة المحتوى 60 لكل صفحة. تظهر الاستضافة (70 سنويًا) والعناية (25 شهريًا) منفصلتين عن تكلفة التنفيذ. رسوم النطاق والضرائب منفصلة، ويؤكد السعر النهائي في عرض مكتوب حسب نطاق المشروع. مصدر الأرقام مركزي في `lib/pricing.ts` لتعديلها بسهولة.

اختيار قالب من الصفحة الرئيسية ينقل المستخدم إلى إنشاء مشروع جديد بالقالب المختار. تغيير اللغة بين العربية والإنجليزية يبدّل اتجاه الواجهة ونصوص الصفحة الرئيسية وصفحة المشاريع والدخول ومحتوى القوالب الافتراضي؛ يحتفظ المحرر بالنص الذي عدّله المستخدم يدويًا.
